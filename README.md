# Cervical Cancer Risk Prediction

## Objective
This project aims to analyze patient-related risk factors associated with positive cervical biopsy outcomes using machine learning techniques.

## Preprocessing & EDA
Completed:
- Hidden missing value detection and handling
- Data type conversion
- Duplicate removal
- Constant feature removal
- Missing value imputation
- Skewness and distribution analysis
- Correlation analysis
- Class imbalance analysis

Highly target-related diagnostic screening variables were removed to focus on meaningful patient risk factors and avoid circular prediction behavior.

## Planned Modeling Workflow
- Train/test split with stratification
- Feature scaling
- Logistic Regression
- Random Forest
- Imbalance handling evaluation
- Hyperparameter tuning
- PCA evaluation
- Model comparison using Recall, F1-score, ROC-AUC, and Confusion Matrix

## Technologies
Python, Pandas, NumPy, Seaborn, Matplotlib, Scikit-learn, imbalanced-learn, Google Colab

## Current Status
Preprocessing and EDA completed. Ready for model training and evaluation.
